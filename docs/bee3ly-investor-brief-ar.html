1. أهداف المشروع

الرؤية

bee3ly تهدف إلى تمكين التاجر المصري — في الملابس، المطاعم، العطور، والتجارة الإلكترونية — من إدارة محادثات العملاء على السوشيال ميديا وتحويلها إلى مبيعات دون فريق دعم كبير. المنتج ليس «شات بوت عام»، بل وكيل مبيعات ذكي يفهم العربية والإنجليزية، يعرف المنتجات والمخزون والشحن، وينشئ طلبات (Orders) ويُبلّغ التاجر فورًا.

الأهداف الاستراتيجية

#الهدفلماذا يهم السوق
1صندوق وارد موحّد (FB, IG, WA — TikTok لاحقًا)التاجر يضيع leads بين تطبيقات متعددة
2وكيل مبيعات AI (رد، مخزون، توصيل، أوردر)أغلب الأسئلة متكررة؛ السرعة = conversion
3Business OS (منتجات، leads، orders، حملات، تحليلات)خط إنتاج مبيعات وليس chatbot منفصل
4مصر أولًا (EGP، محافظات، 01x، InstaPay/Vodafone، RTL)حلول عالمية لا تفهم السياق المحلي
5فصل المنصة عن الدماغ (Bee3ly + AI Service)توسع، استبدال نموذج، امتثال

الهدف التشغيلي (MVP)

تسجيل → Onboarding → منتجات + معرفة البيزنس → (ربط قناة أو محاكاة) → رسالة عميل → AI + أدوات → Lead/Order → إشعار → Dashboard

هذا المسار قابل للتجربة end-to-end اليوم عبر Inbox المحاكاة، وعند تفعيل Meta تمر الرسائل الحقيقية بنفس المسار.

2. المشاكل التي يحلها bee3ly

  • فجوة الرد: تأخر الرد على DM أو التعليقات = خسارة بيع. AI يرد فورًا مع تحويل لبشري عند الحاجة.
  • تشتت القنوات: Messenger و Instagram و WhatsApp منفصلين → Inbox واحد مع تحديث Realtime.
  • أسئلة متكررة: سعر، مقاس، شحن — يُجاب من قاعدة البيانات لا من تخمين AI.
  • فصل المحادثة عن الطلب: Excel و WhatsApp يدوي → Order في النظام + Notification.
  • الدفع المحلي: مراجعة screenshot التحويل وتأكيد التاجر قبل إتمام prepaid.
  • الحملات: ربط محادثات/leads/orders بالحملة (attribution) — الإطلاق على Meta حاليًا بمساعدة وليس Ads API تلقائي.

3. كيف يعمل الحل

قنوات (FB / IG / WA / محاكاة) → Webhooks → Bee3ly: محادثة + JWT تاجر → AI Service (Gemini + أدوات على API) → رد + Order/Lead + إشعار → Realtime → Inbox & Dashboard
مبدأ للمستثمر: AI لا يخترع الأسعار. الأدوات (checkStock, createOrder, getDeliveryInfo…) تقرأ من PostgreSQL.

Stack: React + Vite · NestJS + Prisma + PostgreSQL · Python FastAPI + Gemini · Meta OAuth/Webhooks/WhatsApp Embedded (حسب الإعداد).
