# First beta playbook (MVP validation)

Use this with the first Egyptian business after the vertical slice works.

## Setup checklist

- [ ] Business signs up with real name + business type
- [ ] Completes onboarding (what they sell, area, goal)
- [ ] Adds at least 3 real products with prices (EGP)
- [ ] Fills delivery / hours / FAQs in Settings
- [ ] Connects Meta (or uses Inbox simulation until Meta app is approved)
- [ ] AI agent primary goal = Get orders

## Success path to demo

1. Customer asks price
2. Customer asks size availability
3. Customer says they want to order
4. Customer sends name + phone (`أحمد - 010xxxxxxxx`)
5. Order appears in Orders
6. Owner sees notification in the top bar
